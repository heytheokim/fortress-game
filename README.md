# FORTRESS — 포탄 대전 게임

바람을 읽고 각도와 파워를 맞춰 상대 탱크를 쓰러뜨리는 1:1 포탄 대전 게임입니다.
브라우저에서 바로 플레이할 수 있습니다.

**▶ 플레이하기: https://heytheokim.github.io/fortress-game/**

---

## 조작

| 키 | 기능 |
|---|---|
| `↑` `↓` | 포신 각도 |
| `←` `→` | 이동 (연료 소모) |
| `스페이스` 꾹 | 파워 충전 → 떼면 발사 |
| `1` `2` | 기본샷 / 두 발 (넓게) |
| `S` | 오브 — 게이지 100 필요 |
| `ESC` | 일시정지 |
| `H` | 지난 발사 힌트 |
| `X` | 소리 끄기/켜기 |
| `R` / `M` | 재대결 / 처음 화면 |

## 특징

- **탱크 7종** — 색만 다른 게 아니라 포탄이 날아가고 터지는 방식이 다릅니다
  - 레이븐(균형) · 매머드(한방) · 스톰(광역)
  - 랜스(화살탄, 바람에 강함) · 볼링(굴러가서 터짐)
  - 스웜(공중에서 갈라짐) · 드릴(땅을 깊이 파고 터짐)
- **맵 5종** — 공원 · 초원 · 사막의 밤 · 설원 · 노을 (전부 도트 픽셀아트)
- **아이템** — 하늘에서 낙하산으로 보급품이 떨어집니다 (수리 · 2연발 · 강화탄 · 연료 · 에너지 · 방어막)
- **지형 파괴** — 적 발밑을 파서 떨어뜨릴 수 있습니다
- **AI 난이도 3단계**, 전적·연승 기록 저장

## 기술

외부 라이브러리 없이 **HTML5 Canvas + 순수 JavaScript**로 만들었습니다.
파일은 `index.html` 하나뿐이고, 효과음도 음원 파일 없이 Web Audio API로 직접 생성합니다.

- 고정 타임스텝(120스텝/초)으로 어떤 모니터에서도 같은 속도로 동작
- AI는 게임과 완전히 동일한 물리로 시뮬레이션해 조준 (교과서 포물선 공식은 프레임 단위 이산 물리와 어긋나 사용 불가)
- 밸런스 수치는 조준 오차 × 바람 × 맵을 전수 시뮬레이션해 검증

## 실행

`index.html`을 브라우저로 열면 끝입니다. 설치·빌드 과정이 없습니다.
